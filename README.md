# Forma

Forma — личный трекер прогресса. Сейчас это соло-цели на фиксированное число дней: ежедневная отметка, календарь и стрик. Игровой слой (квесты, XP, 3D-персонаж) в продукте ещё не живой.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Supabase (Auth, Postgres, RLS). Менеджер пакетов — pnpm.

В зависимостях лежат Effector, TanStack Query и Three.js. В `src` они не используются. Подключать их без отдельной задачи не нужно.

## Быстрый старт

```bash
pnpm install
pnpm dev
```

Нужен файл `.env.local`:

```bash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` читается как запасной вариант анонимного ключа. `NEXT_PUBLIC_SITE_URL` нужен, если origin для OAuth нельзя взять из заголовков запроса (локально без него подставляется `http://localhost:3000`).

Полезные команды:

```bash
pnpm lint
pnpm build
pnpm gen:types
```

`pnpm dev:mobile` поднимает dev-сервер на `0.0.0.0`.

## Что умеет трекер

Вход по почте и паролю или через Google. Без сессии основные экраны уходят на `/login`. Профиль создаётся триггером на `auth.users`.

Новая цель сразу активная: режим `solo`, каждый день, срок в днях. Старт — сегодня в таймзоне браузера, конец считается из длительности. Кнопка `+` в нижней навигации открывает форму.

Отметка за сегодня ставится со главной и больше там не снимается. В карточке цели календарь переключает прошедшие и сегодняшний день внутри срока. Будущие дни сервер не принимает. Когда срок вышел, цель сама становится завершённой.

Стрик в шапке считается по всем отметкам пользователя: серия до сегодня, а если сегодня ещё пусто — до вчера. Колонка `goals.current_streak` для этого не используется.

Уровень, XP и карточки «Готово» / «Рекорд» / «XP» на главной — заглушки. Полоска недели на главной отметки пока не показывает.

## Экраны

| Маршрут | Что там |
| --- | --- |
| `/` | Уровень, неделя, стрик, список целей на сегодня |
| `/goals`, `/goals/[id]` | Список целей и календарь отметок |
| `/login`, `/register` | Почта и Google |
| `/settings` | Выход |
| `/quests`, `/statistics` | Пустые страницы |

Нижняя навигация видна только на узком экране. Боковое меню в коде есть, в layout не подключено.

## Архитектура

```txt
src/
├── app/          # маршруты и layout, без бизнес-логики
├── modules/      # фичи: goals, calendar, dashboard, stats, auth, streakPill, LevelCard
├── shared/       # общие UI и хуки, без знания про цели
└── core/         # supabase-клиенты, env, cn
```

Страница собирает готовый экран. Мутации и запросы к базе — server actions в `*Service.ts`. Типы строк — из `src/core/supabase/database.types.ts`. После изменения схемы: миграция, `pnpm exec supabase db push`, `pnpm gen:types`. Как связать CLI с проектом — в `supabase/README.md`.

## Как писать код

- Общий UI — `src/shared/ui`. UI фичи — `src/modules/<feature>/components`.
- `shared` не импортирует продуктовые модули.
- `any` в TypeScript не используем. Исключение — только если тип чужой библиотеки иначе не выразить.
- Комментарий оставляем, когда без него неясно ограничение. Очевидный код не комментируем.
- Стили — Tailwind v4.
